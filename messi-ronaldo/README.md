# Messi vs Ronaldo — Top Sektirme

Zincir’den ayrı mobil arcade. Messi veya Ronaldo seç, topu sektir, çarpanı kilitle.

## Modlar

- **Hat-trick Crash** — her sektirme çarpan artırır; düşünce sıfır
- **Keepy-Uppi** — uzun combo
- **Last Touch** — zirvede perfect timing

## Çalıştırma

```bash
cd messi-ronaldo
npm install
npm run dev
```

Port: `5174`
